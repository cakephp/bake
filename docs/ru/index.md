# Консоль Bake

Консоль bake для CakePHP — ещё один способ быстро начать работу с CakePHP.
Консоль bake может создать любые базовые ингредиенты CakePHP: модели, поведения, представления, помощники, контроллеры, компоненты, тесты, фикстуры и плагины.
Bake умеет создавать гораздо больше, чем просто скелеты классов, и является естественным следующим шагом после создания каркаса приложения.

## Установка

Перед тем как использовать или расширять Bake, убедитесь, что он установлен в вашем приложении.
Bake предоставляется в виде плагина, который можно установить через Composer:

```bash
composer require --dev cakephp/bake:"^4.0"
```

Команда выше установит Bake как зависимость для разработки, поэтому он не будет установлен при деплое на production.

При использовании шаблонов Twig убедитесь, что загружаете плагин `Cake/TwigView` вместе с его bootstrap.
Вы также можете опустить это полностью — тогда плагин Bake загрузит его по мере необходимости.
